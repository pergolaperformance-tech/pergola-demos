Privacy Policy

Concept demo · Last updated July 2, 2026

Elk Hollow is a fictional concept website. This page shows how a real privacy policy would be presented for a project like this — and it accurately describes how this demo behaves.

What we collect

The consultation form asks for your name, phone number, email address, an interest selection, and an optional message. In this demo, that information is validated in your browser and then discarded:

  • Nothing you type is transmitted to a server.
  • Nothing is written to cookies or local storage.
  • No analytics or advertising trackers run on this site.

Fonts and embedded resources

Pages load typefaces from Google Fonts and animation scripts from public CDNs. Those providers receive standard technical request data (such as your IP address and browser details) when the files are fetched, as with any website that uses them.

In a production version

If this site were operating for a real resort, form submissions would be delivered to the operator's booking system, used only to arrange your consultation, retained only as long as needed for that purpose, and deletable on request at any time by writing to the address in the footer.

Contact

Questions about this demo can go to Pergola Performance, the studio that built it, via the contact details on the main page.
